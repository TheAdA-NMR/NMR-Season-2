Development repository for **No Man's Road — Season 2**.

This repository separates the Season 2 **Story / Quest Line** from server-wide systems such as **Factions**, gameplay systems, economy and events.

## Working Rules

- **Story / Quest Line** owns the Season 2 narrative, quest progression, story locations and lore documents.
- **Factions** is a separate server-wide Season 2 system. Story / Quest Line references faction information only when required.
- **Lore Documents** belongs under Story / Quest Line.
- Finalized decisions are marked **CANON**.
- Team decisions that are still being discussed are marked **PENDING**.

## Current Core Direction

**Pavlovo biological experiment → containment breach → Balota recovery operation → wider outbreak → NMR deployment → Rify Base of Operations → Rescue → Containment → Research → Control.**
