# Game Progression

## Core Direction

- S02 should provide enough **economy, quest and personal progression variety** to keep players engaged over the long term.
- Random events and economy progression should help players **gear up for Main Quest, NMR Quest and Bandit Quest content**.
- Progression systems should add meaningful choices and long-term goals without adding unnecessary item clutter or avoidable server load.

## Random Events & Gear-Up Progression

- **Hacked Crate, King of the Hill, Plane Crash and Airdrops** should remain important random-event progression sources.
- Loot from these events should support both economy progression and personal gear progression.
- Event loot should act as one of the main preparation paths before higher-risk **Main Quest / NMR Quest / Bandit Quest** content.

## Player Skill Progression

- The current baseline uses **Zen Skill Tree**.
- Evaluate moving to **Terje Skills** to provide a longer progression curve and more player choices.
- If Terje Skills is selected, Medicine progression should be tuned so skill-point gain remains meaningful without becoming excessive grind.
- The target is for **Terje Skills + Terje Medicine** to complement each other as one coherent progression system.

## Hunting Progression

- The currently used **Admiral's hunting functionality** is not working as intended and should be reviewed/replaced.
- Evaluate an alternative hunting system that can differentiate progression/rewards based on **animal weight**.
- Continue the existing **animal-head trophy** concept as part of hunting progression.

## Fishing Progression

- The current fishing setup provides sufficient **fish variety**.
- Keep the useful fishing progression elements: **fishing rods, bait variety and Fisherman Backpack**.
- Extra items that do not meaningfully improve fishing progression should be reduced where possible.
- Unnecessary additional **storage items** bundled with the fishing content should be avoided/removed where practical to reduce item clutter and server load.
