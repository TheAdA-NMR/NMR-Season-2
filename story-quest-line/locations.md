# Story / Quest Locations

## Main Story / Quest Locations

### Pavlovo Military Base
- Outbreak origin.
- Classified biological experiment and containment breach.

### Balota Air Base Bunker
- Recovery operation endpoint.
- Biological material and advanced weapons-development equipment secured here.

### Rify Bunker / Port / Shipwreck
- NMR Base of Operations in Chernarus.
- Bunker = command / secure operations.
- Shipwreck contaminated zone = active research environment.
- Dedicated port = secure maritime logistics.
