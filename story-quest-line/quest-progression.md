# Quest Progression

## Core Rules

- Main quest progression is sequential.
- Completing one quest unlocks the next quest.
- Bunker entrances use **Punch Cards**.
- Punch Card locations, prerequisites and card-to-bunker assignments will be created together with the questline.
- Storyline and questline should progress in parallel: every major quest should provide a story reveal, map interaction and progression reward.

## Q00 — Safe Haven

On first entry to the server, the player automatically receives a quest directing them toward the protected **Altar Refugee Camp / Safe Haven**.

At Altar:
1. Player reaches the Safe Haven.
2. An NPC provides information / rumor about the NMR storyline.
3. The player learns where the separate NMR Questline Giver NPC can be found.
4. The NMR main questline begins from that contact.

## Progression Pattern

**Quest Complete → Next Quest Unlock → Intel / Item / Punch Card → Location Access → Story Reveal → Reward**
