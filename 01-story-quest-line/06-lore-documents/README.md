# Lore Documents

Lore Documents belongs under **Story / Quest Line**.

These files will carry the Season 2 story in-game through fragmented evidence rather than a single exposition document.

## Planned Categories

- `civilian/` — newspapers, diaries, witness accounts
- `medical/` — hospital records, patient reports, pathology notes
- `military/` — situation reports, recovery manifests, logistics records
- `nmr/` — NMR mission orders, field reports, command directives
- `scientific/` — biological analysis, pathogen research, experiment notes

## Suggested ID System

- `CIV-###`
- `MED-###`
- `MIL-###`
- `NMR-###`
- `SCI-###`

## Design Rule

No single document should reveal the entire truth. Important conclusions should emerge from multiple sources, locations and chapters.
